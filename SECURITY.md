# Security Policy

## Supported Versions

We currently support the latest version with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, send an email to the project maintainer. We will acknowledge
receipt within 48 hours and send a more detailed response within 5 days.

## Process

1. Report the vulnerability via email
2. We will investigate and confirm the issue
3. A fix will be prepared and deployed
4. You will be credited for the discovery (optional)

We appreciate your help in keeping this project secure! 🔒
